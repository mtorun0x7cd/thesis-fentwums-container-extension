# Contributing

This repository holds a **submitted master's thesis**, maintained as its public
record — the LaTeX manuscript, its evaluation harness, and the supporting
example projects. Factual corrections that keep the record accurate are welcome.

## Reporting

- **Security or integrity issues:** follow [`SECURITY.md`](SECURITY.md).
- **Factual corrections, errata, and broken links:** open a concise issue via
  GitHub Issues (enabled), or contact the author below.

The extension under study is vendored as a pinned, read-only git submodule;
changes to its source belong upstream, not here. Please raise substantive
changes to the thesis or its harness as an issue first, so the correction can be
folded into the published record through the normal revision / erratum process.

## Citation

If you reference this work, please cite it via the metadata in
[`CITATION.cff`](CITATION.cff).
