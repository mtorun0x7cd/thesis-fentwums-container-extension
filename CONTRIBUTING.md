# Contributing

This repository holds finished work: the Master's thesis "Design and Implementation of a Modular Architecture for the Transparent Integration of Containerized Execution Environments for Heterogeneous Open-Source Binaries in OneWare Studio" by Mert Torun as deposited, its sources and the evaluation apparatus. It is not developed further and takes no feature contributions.

## Corrections

Report an error in the thesis, the evaluation or the documentation through the issue form **Correction**, with the location, the quoted text, the proposed correction and the evidence, after checking [`ERRATA.md`](ERRATA.md). A matter that should not be public goes by e-mail to [info@mtorun0x7cd.com](mailto:info@mtorun0x7cd.com).

The text of the thesis changes only by errata: the deposited file and the sources at the tag `epub-3597` stay as they are, and a confirmed error is added to `ERRATA.md`.

## The extension

The extension the thesis describes is pinned here as the submodule `FEntwumS.ContainerExtension`, at its state when the thesis was submitted. A change to the extension belongs in its own repository, <https://github.com/FEntwumS/FEntwumS.ContainerExtension>; this repository does not move the pin.

## Pull requests

A pull request that changes the deposited file, the sources of the thesis, the measured results or the evaluation scripts as measured is not merged. Security reports follow [`SECURITY.md`](SECURITY.md).
